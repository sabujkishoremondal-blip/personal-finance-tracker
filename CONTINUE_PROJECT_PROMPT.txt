THINGS TO KNOW BEFORE TOUCHING CODE
-----------------------------------
- All service functions require user_id as the first arg. Do not remove that.
- Available balance is a pure function of the transactions table. If you find
  yourself storing a "current_balance" number anywhere, you are wrong.
- Borrowed money increases the wallet AND records a debt. Money friends owe
  does NOT change the wallet until marked received. Do not merge these.
- Negative balances are allowed. Never block an expense insert on balance.
- Streamlit widget keys can't be reassigned after the widget renders. To
  change the sidebar `nav` radio from a button, set st.session_state["_pending_nav"]
  and st.rerun(); app.py picks it up on next run (see app.py sidebar block).
- OCR is best-effort; users MUST confirm before saving.
- Auth is Streamlit-session-state driven (not cookies). JWT tokens exist only
  for the future Twilio webhook to identify a user from their WhatsApp number.
- Recurring rules use `last_run` for idempotency. Never post the same due-date twice.
